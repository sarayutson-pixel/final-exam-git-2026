# final-exam-git-2026
Repository สำหรับการสอบปฏิบัติปลายภาคเรียน วิชาการพัฒนาซอฟต์แวร์และการทำงานร่วมกัน

## คำชี้แจงสำหรับนักเรียน
1. ห้าม Push งานขึ้น Branch `main` โดยตรง ให้สร้าง Branch ส่วนตัวตามรูปแบบ `exam-เลขที่-ชื่อนักเรียน`
2. สร้างโฟลเดอร์งานของตนเองใน `students/`
3. แก้ไขข้อขัดแย้งของโค้ด (Conflict) ให้ถูกต้องก่อนส่ง Pull Request
